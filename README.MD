# ICT Conscript Admission Test

I have completed the [`01a-swdev-frontend`](challenges/01a-swdev-frontend.MD) challenge for the ICT Conscript Admission Test.

The submission is available to view at https://zeroview.github.io/test-ictconscript-admission/

## Languages and technologies used

- [`SvelteKit`](https://svelte.dev/docs/kit/introduction)
- [`TypeScript`](https://www.typescriptlang.org/)
- [`Tailwind`](https://tailwindcss.com/)
- [`MapLibre`](https://svelte-maplibre-gl.mierune.dev/)
- [`flatpickr`](https://flatpickr.js.org/)
- [`Lucide`](https://lucide.dev/)
- [`pnpm`](https://pnpm.io/)

## Running locally

1. Clone the repository
```
$ gh repo clone zeroview/test-ictconscript-admission && cd test-ictconscript-admission
```

2. Install dependencies and start development server
```
$ pnpm i && pnpm dev
```
